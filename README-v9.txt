BYTEFEST Competition Frontend v9 - Mobile + Compact + Reports UI

Changes from v8:
- One secure-mode start per participant session; no repeated fullscreen gate after every round.
- Phone/tablet team-device mode: fullscreen is not required on coarse/mobile devices; app/tab hiding still triggers security.
- Code Sprint and Bug Hunt challenge layouts are more compact for 1080p and mobile screens.
- Hint panels are smaller.
- New interactive circuit connection workspace for Code Sprint gate questions.
- Competition Admin adds EXPORT EXCEL REPORT and individual RESTART for Code Sprint/Bug Hunt.
- Code Sprint question copy is more logical/narrative instead of step-by-step instructions.

Backend v9 is required for Excel export, restart endpoint, and revised question bank.
